# octomarketer

Claude skills for marketing work.

| Skill | What it does |
|---|---|
| [`influencer-validator`](influencer-validator/) | Vets influencers / creators on fresh data and returns GO / CONDITIONAL / NO-GO for a campaign. |

Install a skill: download its `.skill` file and upload it under Claude Settings → Capabilities → Skills, or copy its folder to `~/.claude/skills/`.
